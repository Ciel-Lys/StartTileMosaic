# StartTileMosaic

简体中文 · [English](README.en.md)

为 Windows 10 原生开始菜单和 Windows 11 上的 ExplorerPatcher 磁贴菜单制作图片磁贴。支持中、宽、大三种尺寸，以及图片拼图和定时轮换。受微软商店版 TileGenie 启发，作为独立项目开发。

## 下载与运行

从 [GitHub Releases](https://github.com/Ciel-Lys/StartTileMosaic/releases/latest) 下载带有 `portable.zip` 后缀的便携包。解压后双击 `TileGenie.exe`。

- **Windows 10** 使用系统自带的磁贴开始菜单，已在 22H2 上验证。
- **Windows 11** 请安装 [ExplorerPatcher](https://github.com/valinet/ExplorerPatcher) 并启用其 Windows 10 风格开始菜单。

开发人员模式可以从首次运行起保持关闭。首次固定时，Windows 会请求管理员授权来信任本机生成的签名证书。

## 编辑与固定

1. 点击「添加图片」或将图片拖入窗口。支持 PNG、JPEG、BMP、GIF 和 TIFF。GIF 使用静态帧。
2. 在「行列布局」中，用画布上方第二排的圆形按钮增减列、切换中号方形与宽磁贴，用左侧按钮增减行。默认两行两列，左宽右方。点击第一排的「大磁贴」可将整张画布切换为 310 × 310 的大磁贴，再点一次即可恢复。
3. 在网格内拖动图片调整裁剪。按住 Ctrl 滚动滚轮可以缩放。多张图片可以分别裁剪，在左侧列表调整顺序并选择轮换间隔。选择「自定义」可输入 1 至 1440 分钟的整数。固定后会在后台安排轮换。
4. 在「全局绑定」中填写 HTTP 或 HTTPS 网址，或点击「选择文件」。Windows 会按文件关联打开文档、图片、程序等文件。每块磁贴只有一个启动目标。选中一块磁贴可为它单独绑定，点「清除」会恢复使用全局设置。点「返回全局绑定」或按 Esc 返回全局范围，此时设置新目标会覆盖单块绑定。未绑定的磁贴会打开 TileGenie 编辑器。请保留 `TileGenie.exe` 和已绑定文件的位置。
5. 点击「固定磁贴」，在开始屏幕按预览顺序排列。图片使用次级磁贴，不在「所有程序」中逐片添加应用入口。

### 自由组合

首次进入「自由组合」时画布为空。点击「添加磁贴」，选择中、宽或大。用左键长按磁贴，等光标变为移动图标后拖到空位，画布随放置位置扩展。右键单击可删除一块磁贴。左键短按可选中磁贴，按下后直接拖动可调整裁剪。

画布可以继续向右扩展。拼图超出开始菜单单组宽度时，TileGenie 会在固定时从左到右分组，保留每块磁贴的图片和尺寸。开始菜单会根据窗口宽度排列各组，组间有系统间距，也可在开始菜单拖动整组调整位置。点击「行列布局」即可返回，当前窗口会记住两个布局。

通过左上角「语言 / Language」可以切换简体中文和 English。界面立即更新，重新打开编辑器时沿用上次选择。

左上角菜单可旋转图片、复位裁剪、设置间距和预览编号。如需取消固定，请在开始菜单中右键点击对应磁贴。

## 保存与安装

源图和裁剪参数保存在 `%LOCALAPPDATA%\TileMosaic\Projects`。新磁贴作为签名 MSIX 安装，显示资源由 Windows 管理。以前用开发人员模式固定的磁贴仍会读取原作品的 Package 文件夹。

固定新磁贴无需启用开发人员模式。首次固定时，编辑器会显示本机签名证书的指纹，征得同意后由 Windows 请求管理员授权，将公钥证书加入本地计算机的「受信任的人」存储。随后可以用同一个证书签名并安装新的磁贴包。签名私钥保存在当前 Windows 用户的个人证书存储中，设置为不可导出。系统管理员禁止旁加载签名应用时，安装仍会受该策略限制。

轮换使用 Windows 动态磁贴通知，实际刷新时间可能受到系统节电和后台设置影响。

## 构建

在项目目录运行 `.\build.ps1`，生成 `dist\TileGenie.exe`。程序使用 Windows 自带的 .NET Framework，运行时无需安装 Windows SDK。编辑器支持 `--library <文件夹>` 指定磁贴资源目录，以及 `--image <图片路径>` 导入图片。
